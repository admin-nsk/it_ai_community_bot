# Добавлена функциональность отправки опросов

## Что добавлено

В админское меню `/send_info` добавлены две новые кнопки:

1. **"Отправить опрос всем"** - отправляет опрос всем пользователям с включенными уведомлениями
2. **"Отправить опрос по событию"** - отправляет опрос участникам конкретного события

## Как это работает

### Отправка опроса всем пользователям

1. Админ выбирает "Отправить опрос всем"
2. Показывается список всех доступных опросов (включая неактивные)
3. После выбора опроса, всем пользователям с `is_allow_notify=true` отправляется сообщение с:
   - Названием опроса
   - Просьбой пройти опрос
   - Кнопкой "Пройти опрос"

### Отправка опроса по событию

1. Админ выбирает "Отправить опрос по событию"
2. Показывается список активных событий
3. После выбора события, показывается список всех доступных опросов
4. После выбора опроса, всем участникам события с `is_allow_notify=true` отправляется сообщение с:
   - Названием события и опроса
   - Просьбой пройти опрос
   - Кнопкой "Пройти опрос"

### Запуск опроса

При нажатии на кнопку "Пройти опрос" запускается соответствующий опрос через существующую систему опросов.

## Изменения в коде

### service/states.py
- Добавлен класс `AdminSendSurveyStates` с состояниями для FSM

### service/database.py
- Добавлен метод `get_all_surveys()` - получение всех опросов (включая неактивные)
- Добавлен метод `get_event_notifiable_users(event_id)` - получение участников события с включенными уведомлениями

### service/bot.py
- Добавлены новые кнопки в админское меню
- Добавлены обработчики для новых действий:
  - `handle_survey_all_selection()` - выбор опроса для отправки всем
  - `handle_survey_event_selection()` - выбор события для отправки опроса
  - `handle_survey_event_survey_selection()` - выбор опроса для конкретного события
- Добавлены новые состояния FSM `AdminSendSurveyStates`
- Зарегистрированы новые обработчики в `register_handlers()`

## Безопасность

- Все новые функции проверяют права суперпользователя
- Обработка ошибок при отправке сообщений
- Автоматическое отключение уведомлений для заблокированных пользователей

## Обратная совместимость

Все изменения полностью совместимы с существующим кодом. Новая функциональность не влияет на работу существующих команд и обработчиков.
